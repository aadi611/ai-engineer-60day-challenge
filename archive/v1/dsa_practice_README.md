 DSA Practice Track

45 min/day, ~2 problems/day, pattern-by-pattern (mirrors the day-by-day pattern
assignments in [../progress_tracker.md](../progress_tracker.md)). Goal: ~90-100
problems by Day 60, covering every pattern that shows up in AI Engineer coding
rounds (they lean array/string/hashmap/graph-heavy, lighter on exotic DP).

## How to use this folder

Create one subfolder per pattern (e.g. `two_pointers/`, `graphs/`) and drop
your solutions in with a one-line note on the pattern/trick used — that note
is what you'll actually reread before an interview, not the code.

```
dsa_practice/
├── arrays_strings/
├── two_pointers/
├── sliding_window/
├── hashmaps/
├── stacks_queues/
├── binary_search/
├── linked_lists/
├── trees/
├── heaps/
├── graphs/
├── backtracking/
├── dp/
├── greedy/
├── union_find/
└── tries/
```
