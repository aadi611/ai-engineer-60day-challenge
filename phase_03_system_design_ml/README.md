# Phase 3: ML/DL & System Design Deep Dive (Days 26-30)

The theory block that backstops both classic ML rounds and GenAI system
design rounds — many AI Engineer loops still include one classic ML
fundamentals round even if the job is 90% GenAI.

## Days

- **Day 26** — Classic ML interview fundamentals: bias-variance tradeoff, regularization (L1/L2), ensemble methods (bagging/boosting), evaluation metrics (precision/recall/F1/ROC-AUC/calibration).
- **Day 27** — DL fundamentals refresher: backprop, CNN/RNN basics, optimizers (SGD/Adam), normalization (batch/layer norm).
- **Day 28** — ML system design framework: data → features → training → serving → monitoring, applied to a non-LLM example (e.g. recommendation or fraud detection).
- **Day 29** — 🎯 GenAI system design framework practice: "design a ChatGPT-like product," "design semantic search at scale."
- **Day 30** — 🎯🎯 Two full timed mock system-design interviews + mid-point retrospective (review Days 1-29: what's solid, what needs another pass).
