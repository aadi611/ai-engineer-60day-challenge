# DSA Practice Track (v2: Track A, odd days)

45 min, ~1-2 problems, pattern by pattern. In v2, DSA runs on **odd days** and security labs on even days
([../security_labs/](../security_labs/README.md)). Target: **~60 problems by Day 80**.
The v1 rotation is in [../archive/v1/dsa_practice_README.md](../archive/v1/dsa_practice_README.md).

## How to use this folder

One subfolder per pattern (already created). Drop each solution in with a one-line note on the pattern/trick.
That note is what you reread before an interview, not the code.
