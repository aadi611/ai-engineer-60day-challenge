# Phase 9: Interview Sprint (Days 78-80)

> v1 reference: [../archive/v1/phase_08_interview_sprint/](../archive/v1/phase_08_interview_sprint/)

## Target roles

AI Engineer / Applied AI Engineer · AI Security Engineer / AI Red Teamer · Agent Platform Engineer
(marketplaces, agent infrastructure, developer platforms) · Forward-deployed / Solutions engineer for agent products.

## Days

- **Day 78: Positioning.** Resume, portfolio and LinkedIn tailored to the three-way profile. Lead with the capstone and
  the red-team report. Draft 6 STAR stories, e.g. a security tradeoff you made, a red-team finding you fixed with
  numbers, a scope cut, a protocol decision (MCP vs A2A), a production incident or load-test surprise, and how you
  restarted this plan.
- **Day 79: Full mock loop.** Coding (DSA) · GenAI/security system design · **AI-security deep dive** ("walk me through
  how you'd stop indirect prompt injection in an agent with email + browser tools") · marketplace design · behavioral.
  Record and self-review.
- **Day 80: Gap-fill + rest.** Fix the top 2-3 weak spots the mocks exposed, skim your cheat sheets, rest.

## Deliverable

Tailored resume, 6 STAR stories, and a self-review from the mock loop.
